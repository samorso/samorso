# Samuel Orso

I am a **research statistician at the University of Geneva** and a **lecturer at HEC Lausanne**. My work focuses on statistical methodology and computational statistics, with an emphasis on methods that remain practical for complex scientific models.

## Research

My current interests include **simulation-based inference and implicit bootstrap methods**, **measurement-error models**, **mixed models**, and **robust statistical inference**.

Much of my work combines statistical theory with efficient implementation in **R and C++**, particularly for problems where likelihood-based inference is difficult or where simulation provides a more natural description of the data-generating mechanism.

## Selected work

### [IBpaper](https://github.com/samorso/IBpaper)

R/C++ research code for iterative-bootstrap methodology, simulations, and reproducible analyses.

### [Monte Carlo simulation with R on UNIGE HPC](https://github.com/samorso/unige-hpc-r)

A practical, reproducible introduction to running Monte Carlo experiments with R, Slurm, and the UNIGE Yggdrasil HPC cluster.

### [Data and Code Management](https://github.com/samorso/dcm-website)

Course materials for *Data and Code Management: From Collection to Application* at HEC Lausanne, covering reproducibility, Git/GitHub, code literacy, data workflows, and responsible use of AI.
